# Portfolio (Next.js 16 / React 19 / Tailwind v4)

Personal site for **Jaden Oca / @jadeneoca**, a content creator ("I make content about decision making"). Two top-level tabs: **Overview** (`/`, the profile home) and **Work with me** (`/work-with-me`), which funnels into a **brand deal** (Beacons media kit link — `creator.mediaKitUrl`) or a **1:1 coaching call** (`creator.bookingUrl`, `$50/hr`). The corporate résumé and the résumé chatbot were **removed** in the 2026-07 revamp (see below).

## Design language — "Coastal" (cool light + navy)
Creator-forward look (the old terminal/TUI aesthetic was retired in the 2026 remodel; the warm cream/gold "Editorial Luxe" palette was replaced 2026-07). Cool light-blue canvas, deep **navy** ink, a single **sky-blue** accent, and full-bleed **navy feature bands** (stats, brand wall, CTA) for rhythm. Big characterful serif headlines + clean geometric sans body, generous whitespace, calm motion. Kept deliberately un-"vibe-coded": no drifting glow blobs, no gimmick "Preferred/For brands" badges, sparing use of uppercase eyebrow labels.

## Visual rules
- **Light-first.** `globals.css` sets `color-scheme: light`. All tokens live in `:root` and are exposed to Tailwind via `@theme inline` (e.g. `bg-bg`, `text-text`, `text-muted`, `text-accent`, `bg-ink-navy`, `text-on-navy`). Palette: bg `#F3F7FC`, surface `#FFFFFF`, text `#16202E`, muted `#55636F`, border `#D5E2EF`, accent sky-blue `#2F72BC`/soft `#8AC2EE` (accent-ink is **white** `#FFFFFF`), navy band `#142338`, on-navy `#EAF2FB`.
- **Sky-blue is accent-only** — CTAs, stat numbers, the `@jadeneoca` handle, link hovers. Use accent for large text / buttons / on-navy; avoid small accent body copy on the light canvas (AA-small risk). Blue on navy is safe.
- **Type:** display **Fraunces** (`font-display`), body **Plus Jakarta Sans** (`font-sans`), italic accent **Instrument Serif** (`font-serif-accent`) — all via `next/font/google` in `layout.tsx`.
- **Shared utility classes** in `globals.css`: `.dark-section`, `.reveal` (scroll-reveal via `animation-timeline: view()`, gated behind `@supports` so non-supporting browsers still show content), `.marquee`/`.marquee-track`, `.hero-glow`, `.btn-primary`, `.btn-ghost`, `.card`/`.card-lift`/`.card-navy`, `.eyebrow`, `.stat-num`, `.link-underline`. All motion respects `prefers-reduced-motion`.

## Architecture
- Global chrome in `src/app/layout.tsx`: just `<SiteNav>` (sticky nav, `src/components/site/SiteNav.tsx`). Two tabs: "Overview" (text link, `/`) + "Work with me" (gold→blue `btn-primary` pill, `/work-with-me`). No floating widget.
- Page sections live in `src/components/site/` — Home/Overview: `Hero` (portrait rounded-rect photo `/headshot.jpeg`, no glow blobs), `StatBand` (IntersectionObserver count-up), `BrandWall` (logo marquee), `AboutBlock`, `WorkTeaser`, `CtaFooter` (its "Work with me" CTA links to `/work-with-me`). UGC (route exists at `/ugc` but is **unlinked** from nav): `UgcHero`, `UgcAccountCard`, `BrandCollabGrid`. Shared: `SocialLinks` (inline SVG icons, `variant="light"|"navy"`).
- `src/app/work-with-me/page.tsx` — server component, two funnel cards (Brand deal → `creator.mediaKitUrl`; 1:1 coaching → `creator.bookingUrl`) + navy closing band.
- Content source of truth: `src/lib/content.ts`. Creator data is the `creator` export (handle, followers, socials, ugcAccounts, brands, contactEmail, bio, **mediaKitUrl**, **bookingUrl**, **coachingRate**). The résumé exports (`profile`/`experiences`/`projects`/`activities`/`education`/`awards`/`skills`) are now **unused** (kept in the file for possible revert; safe to delete if desired).
- Brand logos: `public/logos/brands/*.svg`. Currently **placeholder wordmark SVGs** — swap in real logos at the same paths. Components degrade to a text wordmark if a logo 404s.
- **Removed in the 2026-07 revamp**: `/resume` route, résumé components (`ResumeHero`/`ExperienceList`/`ProjectsList`/`ActivitiesList`/`EducationBlock`), the `Services` home section, `ChatWidget`, and the `/api/chat` route (résumé chatbot).
- **Retired but kept on disk for revert** (do NOT delete without owner sign-off): `src/components/terminal/*`, `src/lib/aiDaily.ts`, the `/ai-daily` route, and the old orphaned `Hero/Section/Reveal/ScrollProgress/Projects/Experience/Education/Activities/Nav/Contact/Footer.tsx`. `/ai-daily` still builds but is unlinked from all nav.

## Next.js 16 conventions (this is NOT the Next.js you know)
Bundled docs in `node_modules/next/dist/docs/` are authoritative — consult them before recalling older App Router conventions.
- `params` and `searchParams` are `Promise`-wrapped — `await` them: `const sp = await searchParams`.
- Use the global `PageProps<'/route'>` and `LayoutProps<'/route'>` helpers (no import needed). Generated by `next dev` / `next build` / `next typegen`.
- Server Components are default; add `'use client'` only when needed (state, hooks, browser APIs).
- `fetch` is no longer cached by default — use the `use cache` directive or wrap in `<Suspense>` for streaming.
- For instant client navigation, Suspense alone isn't enough — see `node_modules/next/dist/docs/01-app/02-guides/instant-navigation.mdx`.
- Tailwind v4 via `@tailwindcss/postcss`; theme tokens defined inline in `globals.css` with `@theme inline` against CSS custom properties — do NOT introduce a separate Tailwind config file.

## Dev-loop gotcha
Turbopack hot-reload is unreliable for `globals.css` rewrites — when changing tokens, kill the dev server and `rm -rf .next` rather than expecting HMR.
