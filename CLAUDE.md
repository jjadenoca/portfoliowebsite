# Portfolio (Next.js 16 / React 19 / Tailwind v4)

Personal site for **Jaden Oca / @financefleap**, a finance & lifestyle content creator. The site leads with content-creation / UGC work; the corporate data résumé is secondary. Three top-level tabs: **Home** (`/`), **UGC Portfolio** (`/ugc`), **Corporate Résumé** (`/resume`). A global resume chatbot (`ChatWidget`) floats on every page.

## Design language — "Editorial Luxe" (light + warm)
Fresh creator-forward look (the old terminal/TUI aesthetic was fully retired in the 2026 remodel). Light cream canvas, deep ink-navy text, a single warm **gold** accent, and full-bleed **navy feature bands** (stats, brand wall, CTA) for rhythm. Big characterful serif headlines + clean geometric sans body, generous whitespace, calm motion.

## Visual rules
- **Light-first.** `globals.css` sets `color-scheme: light`. All tokens live in `:root` and are exposed to Tailwind via `@theme inline` (e.g. `bg-bg`, `text-text`, `text-muted`, `text-accent`, `bg-ink-navy`, `text-on-navy`). Palette: bg `#FBF7F0`, surface `#FFFFFF`, text `#14181F`, muted `#5A6068`, border `#E6DCCC`, accent gold `#C8852A`/`#E8A93C`, navy band `#11161F`, on-navy `#F3EFE7`.
- **Gold is accent-only** — CTAs, stat numbers, the `@financefleap` handle, link hovers. Never gold body copy on cream (fails AA small); gold on navy is safe.
- **Type:** display **Fraunces** (`font-display`), body **Plus Jakarta Sans** (`font-sans`), italic accent **Instrument Serif** (`font-serif-accent`) — all via `next/font/google` in `layout.tsx`.
- **Shared utility classes** in `globals.css`: `.dark-section`, `.reveal` (scroll-reveal via `animation-timeline: view()`, gated behind `@supports` so non-supporting browsers still show content), `.marquee`/`.marquee-track`, `.hero-glow`, `.btn-primary`, `.btn-ghost`, `.card`/`.card-lift`/`.card-navy`, `.eyebrow`, `.stat-num`, `.link-underline`. All motion respects `prefers-reduced-motion`.

## Architecture
- Global chrome in `src/app/layout.tsx`: `<SiteNav>` (sticky tabbed nav, `src/components/site/SiteNav.tsx`) + `<ChatWidget>`.
- Page sections live in `src/components/site/` — Home: `Hero`, `StatBand` (IntersectionObserver count-up), `BrandWall` (logo marquee), `AboutBlock`, `WorkTeaser`, `Services`, `CtaFooter`. UGC: `UgcHero`, `UgcAccountCard`, `BrandCollabGrid`. Résumé: `ResumeHero`, `ExperienceList`, `ProjectsList`, `ActivitiesList`, `EducationBlock`. Shared: `SocialLinks` (inline SVG icons, `variant="light"|"navy"`).
- Content source of truth: `src/lib/content.ts`. Creator data is the `creator` export (handle, followers, socials, ugcAccounts, brands, contactEmail, bio). Résumé data is the existing `profile`/`experiences`/`projects`/`activities`/`education`/`awards`/`skills` exports.
- Brand logos: `public/logos/brands/*.svg`. Currently **placeholder wordmark SVGs** (network was unavailable to fetch real logos) — swap in real brand logos at the same paths. Components degrade to a text wordmark if a logo 404s.
- **Retired but kept on disk for revert** (do NOT delete without owner sign-off): `src/components/terminal/*`, `src/lib/aiDaily.ts`, the `/ai-daily` route, and the old orphaned `Hero/Section/Reveal/ScrollProgress/Projects/Experience/Education/Activities/Nav/Contact/Footer.tsx`. `/ai-daily` still builds but is unlinked from all nav.

## Next.js 16 conventions (this is NOT the Next.js you know)
Bundled docs in `node_modules/next/dist/docs/` are authoritative — consult them before recalling older App Router conventions.
- `params` and `searchParams` are `Promise`-wrapped — `await` them: `const sp = await searchParams`.
- Use the global `PageProps<'/route'>` and `LayoutProps<'/route'>` helpers (no import needed). Generated by `next dev` / `next build` / `next typegen`.
- Server Components are default; add `'use client'` only when needed (state, hooks, browser APIs).
- `fetch` is no longer cached by default — use the `use cache` directive or wrap in `<Suspense>` for streaming.
- For instant client navigation, Suspense alone isn't enough — see `node_modules/next/dist/docs/01-app/02-guides/instant-navigation.mdx`.
- Tailwind v4 via `@tailwindcss/postcss`; theme tokens defined inline in `globals.css` with `@theme inline` against CSS custom properties — do NOT introduce a separate Tailwind config file.

## Dev-loop gotcha
Turbopack hot-reload is unreliable for `globals.css` rewrites — when changing tokens, kill the dev server and `rm -rf .next` rather than expecting HMR.
