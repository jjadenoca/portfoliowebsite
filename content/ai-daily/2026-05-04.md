## 1 big thing: Gemma 4 E2B makes on-device JSON extraction real

Google's Gemma 4 E2B (2B params, 2.4GB, INT4) runs on Android with 6–8GB RAM and emits structured JSON natively. A Reddit dev shipped an offline voice-notes app that parses freeform speech into tagged items — no API, no latency, no cost.

**Why it matters:** This is the missing piece for private, scrappy capture tools. Voice memo → JSON tasks, meeting notes → structured tags — viable now without an API key.

**Yes, but:** It's an extraction engine, not a reasoner. Long, multi-step prompts will fail. Keep prompts short and constrained.

**Try this:** Run E2B via Ollama and feed it `"call dentist at 3, buy milk"` — expect a clean JSON array of `{task, tag, time}`. Useful baseline in minutes.

**Go deeper:** [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/) · [MindStudio breakdown](https://www.mindstudio.ai/blog/gemma-4-edge-deployment-e2b-e4b-models)

## Memtrace gives Claude Code a real codebase memory

Memtrace is an MCP server that builds a bi-temporal AST graph of your repo — 1,500 files indexed in under 2 seconds, zero LLM calls. Claude queries call graphs and blast-radius at runtime in milliseconds.

**Why it matters:** It targets the actual failure mode of long Claude Code sessions — re-reading the same files and editing the wrong caller. Indexing is free; only the trial costs your time.

**Yes, but:** Self-reported benchmarks. No independent validation yet.

**Go deeper:** [GitHub](https://github.com/syncable-dev/memtrace-public)

## Check your Cursor mode before your bill checks you

A developer reports $10 in two prompts and $80 in a week — by manually selecting Opus and GPT-5.5 instead of Auto mode.

**Why it matters:** Cursor's Auto mode routes to cheaper internal models and is cost-controlled. Manual frontier selection passes pricing through directly. Reserve Opus for hard multi-file refactors; Auto handles the rest.
