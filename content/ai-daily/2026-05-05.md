## 1 big thing: DeepSeek V4 Pro matches GPT-5.2 at 17x lower cost

**DeepSeek V4 Pro shipped in April** within 3% of GPT-5.2 on a community agentic benchmark — ranking #4 behind Opus 4.6, GPT-5.2, and Grok 4.3. It ties Opus 4.7 on SWE-bench Verified (80.6 vs 80.8) and beats GPT-5.5 on LiveCodeBench (93.5).

**Why it matters:** For non-latency-sensitive agentic work — BA pipelines, side-app backends, batch synthesis — the default should shift. At ~17x lower per-token, the math flips even for tasks you'd previously route to Opus.

**Yes, but:** FoodTruck Bench is one team's eval, not industry-standard. Data sovereignty stays a real concern for client-facing work.

## Agent Skills encodes senior-engineer discipline for Claude Code

**Addy Osmani shipped Agent Skills** — 20 markdown files and 7 slash commands (/spec, /plan, /build, /test, /review, /ship) enforcing spec-first development, TDD, ~100-line PR sizing, and verification before "done."

**Why it matters:** If Claude Code drifts on your side projects — skipping specs, hallucinated completion — this is the harness. /spec doubles as a real requirements-capture workflow for BA work, before any code is written.

**Yes, but:** Structured prompting, not new capability. Mature CLAUDE.md files get marginal lift.

## A 5-vendor lead pipeline collapses into one Claude skill

**One developer replaced** Apollo → PDL → gap-fill → email verify → manual HubSpot load with a single Claude skill calling APIs sequentially. Old flow: 3 vendors, 15-20% bounce, an hour per batch.

**Why it matters:** The N-vendor waterfall pattern maps cleanly to BA workflows — stakeholder research, multi-source requirements synthesis, deck prep. Any "collect from A, enrich with B, load into C" task is a candidate.

**Yes, but:** Single-user anecdote, no quality metrics on the new output.

## Claude Code v2.1.128 ships Monitor tool and MCP diagnostics

**The May 4 release** adds Monitor for streaming background-script events, /mcp now shows tool counts per server (flagging silently broken connections), and --plugin-dir accepts .zip archives. The LSP bug causing redundant file re-reads is fixed.

**Why it matters:** Monitor is the cleaner pattern for agentic loops — kick off a background test, stream output without polling. /mcp count catches MCP servers that connect but expose nothing.
